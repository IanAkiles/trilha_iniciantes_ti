# Introdução à T.I.

Esta cópia contém o HTML de entrada e os ícones de uma versão compilada do curso. O HTML aponta para arquivos JavaScript e CSS em `assets/`, ausentes no repositório. A configuração do Netlify também referencia um comando de build, mas esta cópia não inclui `package.json`.

Para recuperar a página, use o build completo do projeto original ou publique a partir do código-fonte completo.
